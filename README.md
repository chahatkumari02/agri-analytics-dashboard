### ✨ Key Features
- **👨‍🌾 Farmer Module:** Field & Crop management, Real-time Alerts, Weather Insights
- **🧑‍🔬 Agronomist Module:** Soil Analysis (N-P-K, pH), Crop Health Analytics, Livestock Tracking
- **🚚 Supply Chain Module:** Harvest Forecast, Inventory Management, Event Logs
- **📈 Market Analyst Module:** Price Trends, Demand Forecasting, Regional Analytics
- **🔐 Role-Based Access Control:** 5 Roles - Farmer, Agronomist, Supply, Market, Admin

### ⚙️ How to Run Locally
```bash
# 1. Clone the repo
git clone https://github.com/chahatkumari02/agri-analytics-dashboard.git

# 2. Backend Setup
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload

# 3. Frontend Setup (new terminal)
cd frontend
npm install
npm run dev

Now open http://localhost:5173
